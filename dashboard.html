Clés API & Microphone
Configuration requise
La configuration des clés API n'est possible que depuis l'application de bureau ChurchOverlay (elle passe par le pont sécurisé Electron). En mode « serveur seul » dans un navigateur, définissez GROQ_API_KEY / DEEPGRAM_API_KEY / GEMINI_API_KEY dans un fichier .env.local à la racine de l'application.
Clé gratuite sur console.groq.com/keys.
Secours automatique si Groq ne répond pas. console.deepgram.com.
Améliore les thèmes et l'enrichissement IA. Repli automatique sur Groq si absente. aistudio.google.com/apikey.
🔒 Les clés sont chiffrées sur cet ordinateur (Electron safeStorage) et ne sont jamais renvoyées en clair à cet écran — un champ laissé vide conserve la clé déjà enregistrée.
Accessibilité de l'overlay
Pour les malvoyants, les malentendants et les salles avec un écran éloigné — s'applique immédiatement sur l'overlay projeté.
Traduit en direct ce qui est DIT (pas seulement les versets cités) — utilise un appel IA gratuit supplémentaire par segment de parole. Laissez désactivé si votre assemblée n'en a pas besoin.
Affichage & sortie
La fenêtre d'affichage direct n'est disponible que depuis l'application de bureau ChurchOverlay. En mode « serveur seul » dans un navigateur, ouvrez plutôt /overlay dans un onglet et passez-le en plein écran (F11).
Ouvre l'overlay, l'écran scène ou le diaporama d'annonces en plein écran sur l'écran choisi — chacun peut être ouvert simultanément sur un écran différent (voir recommandations "Stage Display" / "présentation secondaire indépendante").

Caméras IP (téléphones) 0
Pour utiliser plusieurs téléphones comme caméras, sans rien installer sur ce PC. Le bouton 📋 sur chaque caméra copie le lien à coller directement dans une Source Navigateur OBS.

📷 Sans application (QR code)

Scannez avec l'appareil photo du téléphone (pas besoin d'app — s'ouvre dans le navigateur). Valable 10 minutes.

🔧 Manuel (app « IP Webcam » ou équivalent)

Pour une app déjà en cours d'exécution sur un téléphone : notez son adresse (ex. http://192.168.1.50:8080), ajoutez /video, et collez-la ci-dessous.
Habillage caméra (logo, titre) Masqué
Réglage unique : collez le lien ci-dessous dans OBS comme Source Navigateur, empilée au-dessus de votre source caméra (DroidCam, caméra IP...) dans la scène. Ensuite, logo/titre/sous-titre se pilotent depuis ici, en direct — plus besoin de rouvrir OBS.
Logo : image, GIF animé ou vidéo courte (.mp4/.webm, lue en boucle silencieuse) — un fichier vaut pour toute la session, jusqu'à ce qu'il soit remplacé ou retiré.
