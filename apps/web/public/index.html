How it works / Comment ça marche

  1. Start the server Launch ChurchOverlay in Web Server Mode. Lancez ChurchOverlay en mode serveur web.
  2. Copy a page link Take it from this server's console. Each link carries its own access token. Prenez-le dans la console du serveur. Chaque lien contient son propre jeton d'accès.
  3. Open it on the device OBS, a phone, or the stage monitor. OBS, un téléphone ou l'écran de scène.
