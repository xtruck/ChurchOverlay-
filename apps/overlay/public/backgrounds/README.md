# Optional nature backdrop

The local overlay can play `nature-loop.mp4` as a muted, decorative background when its URL includes `?background=nature`. It is opt-in, served with the overlay assets, and never fetched from a third party at runtime. The card gallery has a matching Nature loop (local) background option. Browsers with reduced-motion enabled use a static nature-toned fallback instead of playing the clip.
